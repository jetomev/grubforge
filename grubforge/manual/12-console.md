# On a text console

When the desktop is broken, grubForge still works on a plain text console (**Ctrl+Alt+F3**):

- Run `sudo grubforge` there. A text console has no password window, so sudo asks instead.
- Colours are simpler (the console has 8), symbols are plain (`*` for changed, `+` for ok), and the selected control is the blue one.
- **Help** is on **F1**: a text console sends Ctrl+H as Backspace.
