# Advanced settings

- **Older kernels in submenu**: extra kernels go into an "Advanced options" submenu, keeping the main menu short. On by default.
- **Name for this system**: the name at the start of this system's entries. Usually read from the system automatically; leave it unless you want another name.
- **Keyboard**: where GRUB reads keys from. Change it only if the keyboard doesn't work in the menu.

GRUB names: `GRUB_DISABLE_SUBMENU` (stored backwards, like the search for other systems), `GRUB_DISTRIBUTOR`, `GRUB_TERMINAL_INPUT`.
